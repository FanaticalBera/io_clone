## 재실행

레포 루트에서 Node 24와 설치된 의존성을 사용한다. Windows의 묶음 Node는 `& '.\.tools\node-v24.21.0-win-x64\node.exe'`로 `node` 대신 실행할 수 있다.

```powershell
node --import tsx scripts/bot-audit.ts --bots=14 --phase01 --runtime
node --import tsx scripts/bot-feel-audit.ts --bots=14 --phase01 --runtime
node --import tsx scripts/bot-performance.ts --bots=14 --phase01 --runtime
node --import tsx scripts/bot-performance.ts --bots=14 --phase01 --runtime --hud
node --import tsx scripts/death-audit.ts --bots=14 --phase01
node --import tsx scripts/medium-attack-audit.ts --phase01
```

처음 4개 명령에서 `--runtime`을 빼면 기존 audit 조건이다. 동시에 실행하면 성능 비용을 비교하기 어려우므로 순차 실행한다. 정확한 실행 인자·종료 코드·소스 SHA256·소요 시간은 `manifest.json`에 기록했다. AI를 바꾼 뒤 원래 수치를 재현하려면 별도 checkout에서 기준 게임 소스 `41980bd`와 이 audit 도구 버전을 함께 사용한다.

`summary.json`에는 두 조건별 시드 결과와 성격별 통계, `death-summary.json`에는 정합성 결과·대표 사망 사례, `medium-results.json`에는 실제 사망 원인을 보관했다. 전체 feel/medium trace는 무시되는 `.local/bot-phase02-baseline/`에 보관한다.

게임·AI 소스는 변경하지 않았고 기존 audit 도구만 보완했다: 선택적 `--runtime`, 사망자 종류 집계, 실제 절단 원인 출력. 일반 타입 검사와 수정한 스크립트의 명시적 Node 타입 검사 모두 통과했다. 집계에서는 사망 종류별 합계와 전체 합계의 일치 및 실제 medium 절단 16건을 확인했다.
