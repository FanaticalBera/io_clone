## APK 진동 누락 수정

기존 설치 APK와 소스 매니페스트에 `android.permission.VIBRATE`가 없었다. S24+의 저장 설정은 `killVibration: true`였으며, WebView의 `navigator.vibrate` 함수도 존재했다. 버튼은 요청 성공 메시지를 보여도 기존 APK의 진동 서비스에는 처치 펄스가 재생되지 않았다.

매니페스트에 권한을 추가한 APK를 기존 설치 위에 업데이트했다. 수정 후 S24+의 Android 진동 서비스에 `com.hexhold.game`의 35ms, 55ms 펄스가 모두 `finished`로 기록됐으며 사용자가 같은 ‘진동 테스트’ 버튼을 눌러 실제 진동을 확인했다. 기존 처치 `[35,20,55]`와 사망 `[90,40,120]` 패턴, 진동 설정·숨김 상태·사용자 활성화 검사와 취소 동작은 유지한다. 별도 네이티브 플러그인은 추가하지 않았다.

Android의 직접 진동 호출에 필요한 권한은 [공식 haptics API 문서](https://developer.android.com/develop/ui/views/haptics/haptics-apis)에 설명되어 있다. 이번 실기기 확인은 S24+에 대한 결과이며 모든 기기·모드의 햅틱 체감을 확인한 것은 아니다.

검증 로그·궤적·APK는 로컬 `artifacts/mobile-performance-merge/`에 보관한다. 원시 진동 서비스 덤프에는 다른 앱 기록도 있으므로 커밋·공유하지 않고 이 앱에 관한 요약만 보관한다.
