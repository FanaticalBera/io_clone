# C: 붐빌 때 작은 모양 선택지 — 승인 설계와 탐색 상태

**현재 상태:** 사용자가 이 설계를 승인했고, 수정 B가 탐색 회귀를 유지해 그 위에 C를 구현·비교했다. crowded 같은 모양·크기 반복은77.05%→24.80%(8/8 감소), 확장 공격155→164/1,024다. 중거리는13→11/16이며 새 실패10·13·16 때문에 아직 채택하지 않는다. 실행 코드는 수정 B만으로 두고 C는 동결 소스와 [적용 패치](../evidence/bot-space-shape-review/crowded-candidate.patch)에 보존했다. [상세 보고](bot-ai-space-shape-review.md)를 따른다. 아래는 승인한 원래 설계다.

2026-10-13. B의 경계 1개 추가와 별개인 단일 변경이다. B 탐색 결과를 먼저 보존하고, C가 승인되면 B 위에 적용해 같은 120초 8시드와 두 회귀만 비교한다. 둘을 적용한 최종 후보의 관전·사람 플레이는 한 번에 진행한다.

## 확인된 원인과 목표

기준 crowded 연속 출발 821쌍은 같은 모양 100%, 같은 모양·크기 79.17%다. 관측 머리가 없는 연속 출발은 같은 모양·크기 21.05%다. 현재 crowded는 `bevel=0`, `naturalClosure=false`여서 모든 성격이 RHOMBUS만 만든다. 모양을 늘려도 안전 필터와 후보 점수가 최종 선택을 결정하므로, 반복률이 자동으로 줄어든다고 단정하지 않는다.

목표는 혼잡한 상황에서도 기존 작은 크기 안에서 여러 모양을 시도하는 것이다. 확장 크기나 안전 거리, 공격·귀환 판단, 위험 가중치는 바꾸지 않는다.

## 권장하는 단일 변경

|항목|수치·규칙|
|---|---|
|적용|기존 `crowded` 분기의 모양 선택만 변경|
|crowded 정의|관측된 상대 머리가 현재 위치에서 6칸 이내, 그대로|
|길이·폭|길이 1~2, 폭 1, 기존 분포 그대로|
|안전지킴이 모양|RHOMBUS / NATURAL / BEVEL — 기존 조용한 상황의 모양 범위 유지|
|나머지 성격 모양|RHOMBUS / NATURAL / BEVEL / HOOK|
|배정 방법|기존 `(anchorIndex*6 + direction + memory.seq)`를 모양 목록 길이로 나눈 인덱스, 추가 RNG 없음|
|bevel|BEVEL일 때만 1칸, 나머지는 0; 조용한 상황의 기존 생성은 유지|
|닫기|NATURAL·HOOK의 기존 자기 영토 귀환 탐색을 그대로 사용|
|안전 제한|외부 경로 6칸 이하, 관측 머리와 모든 외부 칸 거리 2칸 초과|
|다른 검사|총 경로 24칸, 성격별 선 한도, 상대 선 차단, 출발 1초 예측, 벽, 보유 비례 위험 강화 전부 유지|
|후보 수|경계×6방향에 각 1개, 기존 수 그대로. 모양별 추가 후보를 동시에 만들지 않음|
|점수|기존 점령·탈취·위험·회전·D와 기존 모양 반복 감점 유지; 새 가산점 없음|

BEVEL의 가장 긴 경로 또는 NATURAL·HOOK의 귀환이 외부 6칸을 넘으면 기존처럼 탈락한다. 살리기 위해 크기·안전 한도를 조정하지 않는다. WIDE/DEEP는 작은 변형의 첫 변경에서 제외한다. 길이·폭을 다시 키워 원인 분리를 흐리지 않기 위해서다.

## 비교와 판단

기준은 B만 적용한 탐색 결과다. C만 추가한 후보와 고정 8시드를 비교한다.

- 주 행동 지표: 같은 생명 안의 실제 인접 확장 출발 중, 양쪽 모두 crowded였던 쌍의 같은 모양·크기 반복률. 모양 이름만 바꿔 낮아진 것처럼 보이지 않게, 이름을 제외하고 회전 정규화한 선택 경로의 기하가 같은 비율과 실제 경로·외부 길이 반복도 함께 보고한다.
- 안전·성장: 보유 영토 시간 평균, 사망, 실제 점령 크기 분포. 시드별 차이·합계·개선/악화 수를 함께 보고한다.
- 필수 탐색 회귀: 중거리 16개(13/16, 실패 ID 5·6·14에서 새 손실 없음), 변경하지 않은 재배치 실제 회수.
- 모양별 생성/안전 통과/선택/실제 출발을 구분한다. 새 모양이 모두 탈락하거나 선택되지 않으면 그 결과를 보고하며, 같은 작업 안에서 안전 검사를 완화하지 않는다.

반복률은 낮아졌지만 보유·사망이 악화되면 채택을 주장하지 않는다. 이 문서는 C 제안이며 현재 게임에는 B만 적용한다. 승인 후 C 구현·탐색, 최종 후보를 고른 뒤 채택 검증 및 한 번의 사람 플레이로 진행한다.
