## 1. 이번 범위와 구현 순서

3A 구조 분리를 유지하고 전술100ms 단독을 관전 후보로 준비한다. 개인별 전략 주기는 비활성으로 보존한다. 3C는 종료하고 3D는 계측 완료이며 추가 재정비 이동/대기는 넣지 않는다. 아래 각 묶음의 초기 제안은 기록으로 보존하되 최신 검토 결정이 우선한다.

|묶음|작업|비교 기준|
|---|---|---|
|3A|기존 계산·호출 순서를 그대로 둔 구조 분리. 기존 출발 안전·재배치 시작 안전 이관|병합 기준과 8시드 궤적·판단·메모리·다음 RNG·예약 순서 모두 동일|
|3B|전술100ms 단독 관전 후보. 전략200ms/slot 위상 유지, 개인별 전략 비활성|3A 대비 같은 세션 교차 비용 측정 후 탐험가·도둑 관전|
|3C|종료. 연속성 가산점·자동 배정 구현하지 않음|기준 사전 변경0.24~0.30%, 종료 결정|
|3D|기존 자기 땅 prefix 계측 완료|추가 기다림·새 이동 미구현|

3B 이후 행동 해시가 이전 단계와 다른 것은 예상되는 변경이다. 대신 각각의 HUD/observer 켜짐·꺼짐에서는 판단·RNG·예약 순서가 같아야 한다. 큰 사망 사례를 이유로 신규 안전 조건을 추가하지 않는다. V=0, 피해 경계 추가 방식, 가산점 상한 +6, 재배치의 봇 전체 6초 대기, 기존 위험·출발 안전 수치는 보존한다. 순위·점유율 격차는 계속 표시 전용이다.

## 2. 주기·유지 시간 제안

모든 시간은30Hz 정수tick으로 정하며 ms는 표시용이다. 현재 관전 후보는 즉시 안전1tick, 전술3tick, 전략6tick/slot 위상만 활성이다. 아래 개인별 전략 범위·최소 유지·집요함·재정비 수치는 보존한 초기 제안이며 현재 실행되지 않는다.

|항목|제안|적용 조건·이유|
|---|---|---|
|즉시 안전|1tick / 33.3ms|기존 벽 look-ahead, 출발·재배치 시작 검사. 기존 머리 사전 필터 7칸과 1초 겹침 예측 유지|
|전술 안전|3tick / 100ms|노출 선이 있거나 ATTACK/RETURN/ESCAPE/REPOSITION 중에 전체 선 위험·귀환 ETA·역공 검토. 전략이 더 일찍 도래하면 그때도 최신 전술 결과 사용|
|선사냥꾼 전략 주기|5~8tick / 166.7~266.7ms|같은 성격 안에서도 개인별 고정 주기|
|영역탐험가 전략 주기|6~10tick / 200~333.3ms|성장 후보 계산의 분산|
|안전지킴이 전략 주기|4~7tick / 133.3~233.3ms|위험 해소 뒤 확장 재개 기회 유지|
|영역도둑 전략 주기|5~9tick / 166.7~300ms|탈취 기회 확인과 계획 지속의 균형|
|전략 주기 절대 상한|10tick / 333.3ms|500ms에 접근하지 않음. 집요함도 이 상한을 늘리지 않음|
|확장·탈취·점수 확장 최소 유지|초기안 18tick / 600ms, 구현 보류|기준 재생에서 적용 대상 0. 3B 후 3C 전에 재측정|
|일반 공격 최소 유지|초기안 9tick / 300ms, 구현 보류|기준 재생에서 적용 대상 0. 안전/완료/무효화/interrupt는 제외|
|집요함 효과|유지 배율을 연속성 가산점 대안으로 교체 제안|아래 9절. 안전·유효성·전술 주기는 그대로|
|귀환 후 재정비|다음 계획의 자기 땅 출발 경계로 이동하는 구간|고정 기다림 없음. 고정 시간 대안이 필요하면 0~12tick / 0~400ms부터 별도 승인·비교|
|집요함 배정|3C 종료로 자동 후보에서 계속 제외|명시 테스트용 정의만 보존. 기존5개 활성 후보·분리 RNG 유지|
|추격 예약 만료|기존 24tick / 800ms 유지|전략이 쉬는 동안 유효한 일반 ATTACK 예약을 전술 주기에서 갱신. 자기 예약 중복 집계 금지|

전술 검사가 필요 없는 자기 땅 안 이동에서는 전략 때 전술 정보를 갱신한다. 첫 외부 칸 출발 검사는 매 tick 유지한다. 기존의 비싼 전체 danger를 매 tick 실행하지 않는다. 출발 검사·전술 검사·전략 판단이 같은 tick에 겹치면 관측과 전술 결과를 그 판단 안에서 한 번 계산해 공유한다. 이전 tick 결과를 경로·생명·소유권 변화 후 재사용하는 캐시는 도입하지 않는다.

## 3. 모듈 계약과 실행 순서

온라인 서버와 LAN은 병합한 `src/shared/room-loop.ts`의 `getBotInputs`를 공통 사용한다. 연습·관전도 같은 디렉터를 유지한다.

|모듈|책임|
|---|---|
|`bot-immediate-safety.ts`|이미 있는 출발 안전·재배치 시작 안전·벽 look-ahead. 기존 조건을 옮기며 새 임계값은 추가하지 않음|
|`bot-plan-validity.ts` (3A 생성)|기존 정체·공격 상태·대상 선·귀환 지점 판정만 이관. 생명 초기화는 조정자에 보존. 확대된 검사 빈도는 3B 승인 후|
|`bot-tactical.ts` (3A 생성)|기존 danger·귀환 ETA·생존 역공·조기 귀환 판정을 이동. 전략 후보 점수와 구분|
|`bot-strategy.ts` (3A 생성)|기존 확장·공격·탈취 후보와 선택을 이동. 안전 판정을 완화하거나 가산점을 바꾸지 않음|
|`bot-scheduler.ts` (3A 생성)|현재 공통 주기·slot 위상. 개인별 전략·전술 기한은 3B 승인 후 확장|
|`bot-director.ts`|실제 전략 판단 순서와 추격 예약. 즉시 안전을 슬롯 순서 셔플에 묶지 않음|
|`bot.ts`|공개 API를 유지하는 조정자. 기존 테스트와 연습 호출을 보존|

3A는 함수를 분리하되 현재 순서·주기·RNG 호출 위치를 유지한다. **3A가 해시 일치를 통과하기 전 3B 값을 넣지 않는다.**

3B의 tick 처리는 다음 순서로 제안한다.

1. 생명 및 실제 점령·피해 사건을 현재 의미대로 반영한다. 행동 판단을 쉬어도 사건을 놓치지 않는다.
2. 싸고 즉각 확인 가능한 유효성 및 안전을 검사한다. 생명/대상 소멸, 남은 자기 땅 경로 소유권 상실은 유지 시간과 무관하게 처리한다.
3. 전술 도래 시 전체 선 위험·귀환 ETA·역공을 검사한다. 관측 정보 및 시간에 따라 달라지는 유효성도 여기서 갱신한다.
4. ESCAPE·즉각적인 생존 역공·기존 허용된 긴급 공격 전환을 우선한다. 다른 유효 계획의 최소 유지가 이를 막지 않는다.
5. 전략 도래 또는 무효화로 인한 재판단 시 전략 후보를 평가한다. 기본 최소 유지 도입은 사전 측정 0건으로 보류하고 3B 후 다시 확인한다.
6. 최종 선택으로 예약을 반영하고 조향한다. 전략을 건너뛰었다는 이유만으로 ATTACK 예약을 방치하거나 풀지 않는다.

새 안전 예외나 공격 허용 확률을 만들지 않는다. 현재의 `interrupt` 공격 기회는 기존 조건을 통과할 때 전환할 수 있다. 일반적인 안전한 공격을 전부 생존 예외로 예약 상한을 우회하게 만들지 않는다. HOME_CAPTURE는 한 tick의 점령 처리에서 즉시 발생할 수 있으므로 이 구조 분리만으로 사라진다고 약속하지 않는다.

## 4. 시드와 분산·계획 무효화

개인별 주기·시작 위상·재정비 길이는 `botSeed(seed, slot)`에서 분리한 **스케줄 전용 RNG**로 최초 한 번 뽑는다. 구체 도메인은 `0x6c5e9d13`을 제안한다. 행동·성격 셔플·특성·닉네임·예약 순서 RNG를 소비하지 않는다. 봇별 주기에 맞는 시작 위상을 사용하며 `slot % 공통 interval`을 대체한다. 같은 참가자의 부활은 프로필을 유지하고 기한·활성 계획만 새 생명에 맞춰 초기화한다. 참가자 교체는 기존 교체 seed 규칙을 유지한다.

집요함은 전략 주기를 늦추거나 공격 점수·위험 예산을 올리지 않는다. 특성 후보 활성화 자체로 특성 분포와 행동이 바뀌므로 3C를 독립 비교한다.

|무효화 원인|검사·처리 제안|
|---|---|
|자신·대상의 사망/생명 변경/이탈|매 tick 공개 생명 상태 확인, 기존 예약 즉시 해제|
|공격 대상 선 소멸|현재 계획이 겨냥한 관측 가능한 선을 확인. 같은 위치의 새 생명/다른 선에 예약을 붙이지 않음|
|귀환 지점 탈취·자기 땅 경로 상실|공개 owners로 계획의 남은 자기 땅 구간/귀환 지점을 확인. 최소 유지 무시|
|관측 정보 만료|대상이 지역 관측에서 사라지면 원격 머리·선 추적을 계속하지 않음. 현재 시각으로 유효성 재평가|
|진행 불가·정체|현재 코드의 정체 판정 값을 보존. 별도의 더 긴 집요함 정체 시간을 추가하지 않음|
|새로운 치명적 위험·생존 역공|즉시/전술 안전 결과가 계획 유지·귀환 재정비보다 우선|
|귀환 재정비 경로 상실/경로 없음|재정비를 종료하고 현재 규칙으로 재판단. 제자리 대기·영토 밖 강제 이동 금지|

유효성은 체크 빈도만으로 보장되지 않는다. 남은 경로의 어떤 부분을 확인했는지, 정보가 언제 만료됐는지, 전술 스냅샷 tick과 취소 원인을 HUD에 표시한다. 유지 중이란 이유로 무효화 검사를 건너뛰지 않는다.

## 10. 사용자 검토 반영 — 재정비는 다음 출발 경계 이동

현재 `planExpansion`에도 자기 위치에서 선택한 경계까지 자기 땅만 지나는 prefix(max 10칸)가 이미 들어 있다. 별도의 시간을 더 기다리게 하기보다 **새 계획 선택 → 그 계획의 자기 땅 prefix 이동 → 첫 외부 칸 출발**을 재정비로 정의하는 안을 우선 추천한다. prefix는 기존 총 경로 24칸 한도에 그대로 포함하며 거리·선 길이 제한을 늘리지 않는다. 이동할 prefix가 없으면 재정비 시간은 0이다.

도착·자기 땅 경로 소유권 변화·새 위협·대상 무효화로 끝을 결정한다. 시간 충족을 위해 서 있거나 반대 방향으로 추가 왕복하지 않는다. 원거리 피해 대응 REPOSITION과 별도로 설명하고, 기존 즉시 출발 안전과 전술 안전을 계속 적용한다. 먼저 HUD/계측에서 prefix 이동 구간과 시간·도착/중단 원인을 분리할 수 있다. 경로 노드가 자기 땅이라는 이유만으로 실제 턴 궤적도 자기 땅 안이라고 가정하지 않는다. 실제 소유 칸·선 0 조건으로 준비 구간을 세고, 경계 전에 노출 선이 생기면 준비로 계속 세지 않고 기존 전술 안전에 따른 노출 구간으로 분류한다. 이를 새 행동이라고 포장하지 않는다.

기존 prefix로 부족하여 별도 고정 시간 대안이 필요해지는 경우에만 **0~400ms**로 시작하는 갈래를 제안한다. 승인 후 0ms 기준과 동일 8시드로 보유 시간 평균(주 지표)·최종 보유·사망·공격 기회·비용을 비교하며 현재는 그 갈래를 구현/측정하지 않았다.

## 11. 추가 합격 지표와 master 통합 방침

‘2초 안 목표 A→B→A’, ‘2초 안 BotGoal 모드 A→B→A’, ‘근접 상태 봇 시간 1분당 계획 교체’ 및 각각의 자발적 부분집합을 추가한다. 기준은 [3A 결과](bot-ai-phase03a.md)와 증거 CSV에 있다. 완료·안전·무효화·허용 interrupt와 자발 교체를 분리하며 기준 0인 자발 지표에 증감률을 쓰지 않는다. 새 수치 합격선은 승인 전이다. 자발적 지표가 7/8 동일 방향으로 늘고 모든 leave-one-out 방향이 유지되면 재검토하는 안을 제안한다.

master에 실험 결과를 반영하는 것은 **3단계 완료 후**로 보류한다. 그때까지 다음 묶음을 시작하기 전에 로컬 master를 확인하며, 특히 shared/클라이언트 변경은 실험 브랜치에 먼저 통합한다. 병합 직전 실험 행동 기준과 같은 8시드의 궤적·판단·RNG를 비교한다. 현재 기준은 c84fc7a 행동이며 3B 이후에는 직전 승인된 실험 행동이 기준이다. master 룰 변경 등으로 불일치하면 원인과 결과를 보고하고 새 golden으로 덮어쓰지 않는다.

3B에서는 전략을 쉬는 tick의 일반 interrupt 공격 선택도 예약을 즉시 반영해야 한다. 실제 선택하는 봇의 순서를 예약용 RNG로 결정하고 같은 tick 뒤 봇이 앞 예약을 보도록 한다. 전략이 안 돌았다는 이유로 일반 공격을 미등록하거나 생존 예외로 우회하지 않는다. 전술/전략이 겹친 tick에서는 같은 관측을 공유하고, 둘 다 쉬는 tick만 기존 가벼운 관측을 쓴다. 이 예약·관측 검증은 3B 승인 후 구현할 필수 테스트다.


## 12. 3A 결과 검토 후 승인 범위와 결과

3B 전술 100ms·개인별 전략 주기를 수치표대로 적용했다. 3C는 3A 기준 재생에서 C1(최대1, D 공유 상한)과 C2(최대2, 별도 상한)를 비교했으며 집요함 배정/가산은 런타임에 활성화하지 않았다. C2도 기본 점수 10% 제한을 유지한다. 5,393번 일반 후보 선택에서 잠재 변경은 13/16회, C=0 재정렬 불일치는 0회다. 대안의 추가 변화는 3회로 방향 구분 불가이며 체감 개선으로 해석하지 않는다.

3D는 실제 자기 소유 칸·선0인 기존 prefix 시간과 경계 도착/경계 전 노출/취소를 기록했다. 고정 대기·새 REPOSITION·추가 이동은 없다. [근접 상황 계획 선택 제안](bot-ai-near-plan-proposal.md)은 별도 승인 후 독립 비교할 안이며 구현하지 않았다. 기존 안전 필터를 완화하지 않는다.

3B의 8시드 보유 평균 +3.91%, 사망 +11.11%, tick 비용 +3.86%는 재검토 한도 안이며 벽 사망0·예약 최대3·비간섭을 통과했다. 되찾기는 −14.72%, 탐험가–도둑 TV는 0.1776→0.0926, 근접 교체는 47.42→54.26회/근접 봇분이다. 이 변화는 각각 사전 방향 기준에 미달하지만 성격 차이·근접 반복은 관전 및 추가 검토 대상이다. 3B가 왔다 갔다를 해결했다고 단정하거나 자동으로 3C를 구현하지 않는다. 결과의 master 반영은 계속 3단계 완료 후다.


## 13. 2026-10-13 검토 확정

전체3B와 두 분리 갈래는 아직 채택하지 않는다. [분리 실험 보고서](bot-ai-phase03b-separation.md)에 성격별 탈취, TV, 원인별 사망, 보유 시간 평균, 근접 교체, 2초 목표/모드 왕복 및 실제 계획 안전 중단을 정리했다. 전략 주기·위상만 적용하면 보유 증가와 되찾기 감소가 각각7/8 방향 신호다. 전술만은 탈취/회수 합계가 기준에 가깝지만 TV는6/8 감소하므로 자동 채택하지 않는다. 실험을 위해 기본 게임 소스를 전환하지 않았으며 비교용 전체3B 코드는 실험 브랜치에 남긴다. master 반영 보류도 유지한다.
