# 열린 공간 경계 분석과 B 단일 변경 제안

**제안: 기존 성격별 경계6개와 피해 경계최대2개를 그대로 두고, 열린 공간 경계를 최대1개 추가한다.** 새 가산점·모양·크기·안전 완화·강제 계획 취소는 넣지 않는다. 구현은 사용자 승인 후다. A닉네임은 별도 파일 검토, C새모양은B 적용과 관전 후로 보류한다.

기준은 master 6578389(c8f825d 채택 내용)다. 고정 시드 4·19·73·11·31·47·101·137의 120초를 **각각 한 번씩** 재생했다. 별도shadow에서는 새 경계의 후보만 평가했고 원래 후보 전체를 다시 돌리지 않았다. 행동/배정/예약 RNG를 소비하지 않는 post-native RNG 복제본을 사용했다. 추가1개/2개 결과는 같은 재생에서 함께 계산한 반사실 결과이며 실제 B 실행 결과가 아니다.

## 움직임 유사도 기준값 — C는 측정만

한 봇의 같은 생명에서 인접한 실제 확장 출발끼리만 비교한다. 출발 당시 목표EXPAND/STEAL이고 선택 계획의 생명이 일치한 경우를 확장 출발로 분류하며 ATTACK/RETURN 출발은 섞지 않는다. 사망/부활을 가로질러 반복으로 세지 않는다. 방향은 첫 외부 칸으로 실제 들어간 이웃 방향이다. 같은 모양·크기는 회전을0으로 정규화한 expansionSides의 변 방향/길이가 같다는 뜻이며, 쓰이지 않는 bevel 값 차이를 별개 모양으로 세지 않는다. 실제 조기 닫힘/회수 경로는 계획과 달라질 수 있어 경로 길이+노출 길이 반복도 별도로 보고한다.

전체의 같은 모양 반복 46.26%, 같은 모양·크기 반복 27.79%, 같은 모양·계획 경로/노출 길이 반복 15.96%다. 같은 실제 출발 칸 반복은 3.82%, 출발 칸 이동 중앙값3/p90 8칸이다. 방향의 전체 합계는 고르게 보여도 개별 봇과 국소 혼잡 장면을 대신하지 않는다.

두 인접 출발 모두 혼잡한 경우 821쌍에서 같은 모양100%, 같은 모양·크기79.17%다. 두 출발 모두 관측 머리0명이었던 경우의 같은 모양·크기는21.05%다. 기존 crowded 분기가 RHOMBUS/길이1~2/폭1로 제한하므로, 붙어 있을 때 비슷해 보인다는 관전과 맞는 제한이 존재한다. 이것만으로 혼잡이 성장/사망의 원인이라고 단정하지 않는다.

최대1개를 먼저 권한다. 같은 시점 선택 변경18.31%로 제안 근거가 있고, 최대2개는26.99%지만 후보 생성 비용과 행동 변화 폭이 더 크다. 비용 개선/생존 개선/시드별 방향 신호를 아직 측정한 것으로 표시하지 않는다. 승인 후 하나만 실제 적용해120초8시드의 보유·사망·점령 크기+중거리16개+실제회수부터 본다.

## 탐색 검증과 범위 경계

읽기 전용 기준의 보유 평균3073.00, 사망79, 실제 점령 평균13.83·중앙값10·p90 32·최대105다. 기존 값과 같은 결과로 B 개선이 아니다. 중거리13/16·새손실0(ID5·6·14 유지), 실제 재배치t103도착/t190에5칸회수·사망0이다. 450tick source/분석 비간섭 probe 및8시드 궤적·메모리·RNG·예약·보유 일치를 확인했다.

앞으로 탐색은120초8시드 보유·사망·점령 분포+중거리16개+재배치 회수로 제한한다. 채택은 선택한 조합 하나만240초·확장1,024·observer 없는 비용·전체 테스트, 이후 사용자 플레이로 진행한다. 지금은 채택 검증·실제 B/C 행동·닉네임 배정을 실행하지 않았다. master/원격은 수정하지 않았다.
