# 2.5단계: D 계획과 실제 회수 진단

2026-10-10. 진단·지도 표시·seed 73 재현 완료. 행동 수치·위험 검사·공격 조건·판단 주기·부활 규칙은 유지했다. REPOSITION과 3단계는 계속 보류한다.

관전에서 D가 붙은 봇이 피해 반대쪽으로 확장하고 이후 상대가 죽는 장면이 보고됐다. D는 계획 생성 당시의 예상 피해 칸 가산점이며, 실제 회수나 처치를 보장하지 않는다. 이번 작업은 그 차이를 기록한다. 사용자가 본 A/B의 슬롯·시각은 확인되지 않아 정확히 같은 사건이라고 주장하지 않는다.

## 관전 표시

HUD 상단에 `예상 되찾기 N칸 → 실제 M칸`, 예상 밖 회수, 종료 시 유지 칸, 계획 번호·생명·선택 tick·종료 상태를 표시한다. 상세에는 일반 탈취와 중립 점령, 조기 귀환·위험 귀환·공격 전환, 관련 사망의 실제 처치자와 엔진 원인을 보여준다. 최근 D 계획 결과를 최대 3개 따로 보여주므로 다음 일반 확장으로 바뀌어도 결과를 확인할 수 있다.

선택 봇의 지도 표시는 노랑=현재 피해 기억, 하늘색=표시된 계획의 예상 피해 칸, 초록=최근 완료 D 계획에서 회수했고 현재 보유한 칸이다. 색뿐 아니라 HUD의 칸 수를 함께 본다. 과거 생명 결과는 지도에 올리지 않는다. 선택 변경·나가기·다른 경기에서 표시를 정리한다. 개발/test의 debug=1 경로만 활성화하며 일반 게임에는 표시와 기록 수집이 없다.

## 정확한 기록과 제한

점령 승자가 확정된 뒤, 실제 소유권 이전 직전의 주인을 보존하고 이전 직후·영토 정리/사망 직전에 관측한다. 옵트인 observer가 없으면 셀 배열을 만들지 않는다. 따라서 같은 tick에 회수했다가 죽어 중립화된 사건도 `회수 N / 종료 시 유지 0 / 사망`으로 남는다. 부활 지급과 사망 중립화 자체는 점령·회수로 세지 않는다.

예상 피해 칸은 계획 선택 당시의 전체 예상 점령에서, 피해 기억과 관측 범위 조건에 해당하는 칸이다. 이미 계산된 봇 계획을 읽고 RNG를 소비하지 않는다. 실제 이전 칸은 예상 칸 회수 / 예상 밖 기억된 피해 칸 회수 / 일반 상대 땅 탈취 / 일반 중립 점령으로 중복 없이 분류한다. A→B→C로 넘어간 칸도 A의 피해 기억에 해당하면 C로부터의 회수다.

공격으로 전환되면 기존 D 계획의 귀속을 닫는다. 이후 공격에서 생긴 점령이나 처치를 그 D 계획의 회수로 합치지 않는다. 조기/위험 귀환은 실행 변경으로 기록하고 실제 귀환 점령을 원래 기대와 비교한다. 같은 목표라도 새 확장 계획이면 이전 기록을 닫는다. 생명 변경·사망·미완료 측정 종료를 구분한다.

런타임은 봇마다 최근 6개 계획, 계획별 이동 칸 최대 64개(초과 표시), 실행 변경 최대 8개, 관련 사망 최대 4개만 보존한다. 예상/실제 피해 셀은 기존 96칸 기억 범위에 따른다. 계획별 회수 칸은 중복을 제거한다. 회수와 종료/현재 보유는 다르며 동일 칸의 재회수가 여러 계획에서 반복될 수 있다. 새 진단의 합계는 이전 tick 경계의 탈취 기반 되찾기 지표와 정의가 달라 기존 8시드 균형 지표를 대체하지 않는다.
