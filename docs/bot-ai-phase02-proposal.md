# 봇 AI 2단계 초기값 제안

작성: 2026-10-10. 상태: **수치 확인 전 제안**. 이번 준비 작업은 기준값 기록과 수치 제안이며 2단계 게임 코드는 아직 구현하지 않았다.

기준 AI는 `41980bd`. 0+1단계 사용자 관전에서 안전지킴이의 회피 후 성장, 선사냥꾼의 공격, 영역도둑의 탈취, 탐험가의 확장을 확인했다. 선사냥꾼의 기회 선택은 대치 표본이 적어 잠정 관찰로 남긴다. 반복 침범에도 반대쪽 확장을 이어가는 장면은 2·3단계 후속 검증 사례다.

## 구현 범위

참가자 ID별 사건 기억·감쇠, pressure·grudge, 공개 순위·점유율, Vengeful 활성화, 디렉터의 계획 추격 예약을 구현한다. 성격별 기존 최종 범위와 즉시·전술 안전 판정을 유지한다. 아래 값은 한 설정 객체에 모으고 진단 출력에도 설정 버전을 기록한다.

반복 침범의 상대 우선순위는 높일 수 있지만, 관측 범위 밖 상대의 위치를 알거나 멀리 있는 방어 지점으로 자동 귀환하는 기능을 뜻하지 않는다. 전략·전술 분리와 목표 유지·무효화는 3단계, 성장 정체 대응은 4단계다.

## 1. 사건 기억

| 항목 | 제안 초기값 | 의미와 이유 |
| --- | --- | --- |
| 기억 범위 | 상대별 grudge 0–20 | 한 상대가 모든 선택을 지배하지 않게 상한을 둔다. 키는 참가자 ID다. |
| 나를 죽인 상대 | +5 / 사망 사건 1회 | PRD 확정값. 피해자 ID + life ID 또는 고유 사건 ID로 중복을 막는다. |
| 큰 영토 탈취 기준 N | 6칸 | 기본 스폰 7칸에 가까운 피해를 유의미한 침범으로 본다. 관측 가능한 한 점령 사건에서 실제 내 소유→상대 소유로 바뀐 칸을 센다. |
| N칸 이상 탈취 | +3 / 점령 사건 1회 | PRD 확정값. 칸마다 적립하지 않는다. |
| 탈취 재적립 대기 | 상대별 2초 | 같은 상대의 연속 점령으로 원한이 급증하는 것을 줄인다. 대기 중의 사건은 나중에 소급 적립하지 않는다. |
| 내 노출 선 접근 거리 | 3칸 이내 | 관측된 상대 머리와 내 노출 선 사이의 최소 hex 거리. 단발 접근은 기존 위험 판정에만 반영한다. |
| 접근·침입 재진입 인정 | 범위 밖에서 0.5초 이상 관측한 뒤 재진입 | 경계에서 흔들리는 한 번의 접근을 여러 번 세지 않는다. 관측 소실을 범위 밖 진출로 취급하지 않는다. |
| 반복 접근 기준 | 10초 안의 별개 접근 2회 | 매 판단마다 적립하는 대신 반복 사건만 기억한다. |
| 반복 접근 가중치 | +0.5 | 접근만으로 공격성이 급증하지 않게 약하게 시작한다. |
| 반복 침입 범위 | 상대 머리가 현재 내 영토에 진입 | 경계 인접 체류만으로 침입을 만들어 내지 않는다. 실제 소유칸 진입을 관측한다. |
| 반복 침입 기준 | 10초 안의 별개 진입 2회 | 같은 영역에 머무는 동안은 1개 사건이다. |
| 반복 침입 가중치 | +1 | PRD 초기 후보값을 유지한다. |
| 접근·침입 재적립 대기 | 상대·사건 종류별 4초 | 재진입하더라도 연속 적립 빈도를 제한한다. |
| 반복 사건 중복 | 같은 머리 진입은 큰 가중치 하나만 | 선 접근과 영토 침입이 같은 진입이면 +1과 +0.5를 합산하지 않는다. |
| 일반 원한 감쇠 | 반감기 45초 | 부활 이후에도 기억하되 오래된 사건의 영향은 줄인다. match tick 기준으로 사망·부활 대기 중에도 감쇠한다. |
| Vengeful 감쇠 | 반감기 90초 | 사건의 +5·+3은 그대로 두고 오래 기억하는 방식으로 복수심을 표현한다. |
| 기억 삭제 기준 | 0.1 미만 | 영향 없는 오래된 항목을 정리한다. |
| 내가 그 상대 처치 | 남은 원한 ×0.25 | 복수를 달성한 뒤 75%를 해소한다. |
| 상대가 다른 이유로 사망 | 남은 원한 ×0.50 | 위협이 사라지면 절반 해소하되 기억은 남긴다. 공개 사망 사실·ID만 사용한다. |
| 자기 사망·부활 | 기억 유지 | 새 생명의 경로·현장 접근 상태는 초기화하고 원한과 최근 사건 중복 방지 정보는 보존한다. |
| 상대 이탈·ID 교체 | 이전 ID 기억 정리 | 같은 슬롯의 새 참가자에게 이전 원한을 넘기지 않는다. |

반복 2회로 한 번 적립하면 해당 반복 집계는 소비한다. 재적립하려면 대기 시간 이후 별개 사건 2회를 다시 충족해야 한다. 같은 사건을 여러 window에 재사용하지 않는다. 관측이 끊긴 구간에는 미관측 이동이나 추가 사건을 추정하지 않는다.

기억 표본은 자기 사망, 공개된 상대 사망·이탈 사실, 당시 관측 범위(현재 12칸) 안에서 확인한 침범만 사용한다. 전역 사건의 위치·선·이동 방향을 넘기지 않는다. 공격 평가에는 상대의 현재 지역 관측이 필요하다.

## 2. pressure와 판단 가중치

| 항목 | 제안 초기값 | 의미와 이유 |
| --- | --- | --- |
| pressure 범위 | 0–1 | 현재 위험과 불리함을 정규화한다. |
| 최근 피해 window | 10초 | 오래전 피해가 현재 공포를 계속 유지하지 않게 한다. 사망 시 영토 초기화 손실은 제외한다. |
| pressure 구성 | 선 위협 0.50 + 최근 탈취 피해 0.35 + 공개 점유율 격차 0.15 | 현재 위험을 가장 크게, 순위 차이를 가장 작게 반영한다. 1위 공격 점수는 추가하지 않는다. |
| 선 위협 입력 | 기존 danger이면 1, 아니면 0 | 새로운 위험 탐색을 더하지 않는다. 실제 안전 대응은 pressure 평활화를 기다리지 않는다. |
| 최근 피해 입력 | 10초간 관측된 탈취칸 / max(10초 전 내 영토칸, 스폰칸) | 결과는 0–1로 제한한다. |
| 점유율 격차 입력 | (공개 1위 점유율 − 내 점유율) / 15%p | 결과는 0–1로 제한한다. 자기 불리함에만 반영한다. |
| pressure 상승·하강 | 상승 시정수 1초 / 하강 시정수 4초 | 위험 해소 후 조금씩 진정한다. tick 경과 기반 EMA다. |
| pressure 최대 효과 | 확장 배율 ×0.92, 위험 가중 배율 ×1.10 | p=1일 때 상한. 중간 값은 선형 보간하며 성격별 최종 범위로 제한한다. |
| 원한의 공격 점수 | +0.6 × grudge, 최대 +12 | 유효한 해당 상대 공격 기회를 더 선호한다. 기존 경로·귀환 ETA·역절단 검사 이후 적용한다. |
| 원한의 공격 계수 | 성격 공격 계수 범위 폭의 최대 +10% | grudge/20에 비례해 기존 계수에 더한 뒤 성격 범위로 제한한다. |
| Vengeful 추가 효과 | 원한 공격 점수 ×1.25, 최종 +12 상한 유지 | 작은 기억도 더 강하게 반영한다. 생존 제약은 동일하다. |

pressure 조절은 정체성의 개인차를 변경하지 않고 해당 판단의 임시 값으로 계산한다. 원한의 공격 점수와 계수 효과는 HUD에서 각각 표시한다. 경로가 불가능하거나 관측 기회가 없는 공격을 원한으로 가능하게 만들지 않는다.

현재 안전지킴이 공격 계수 범위는 0.01–0.06이다. PRD의 0.20→0.45는 설계 예시이며 현재 범위를 확대하는 근거로 사용하지 않는다. 범위 절단으로 일부 특성 차이가 약해지는 기존 튜닝 메모는 유지한다.

Vengeful 활성화 후 자동 배정 후보는 Coward/Gambler/Opportunist/Territorial/Vengeful의 5개다. Guardian+Gambler는 계속 제외한다. Persistent는 3단계까지 자동 배정에서 제외한다. 배정 RNG와 행동 RNG 분리는 유지한다.

## 3. 계획 추격 예약

| 항목 | 초기값 / 규칙 | 근거 |
| --- | --- | --- |
| 계획 추격 최대 | 대상당 3명 | PRD 확정값. 사람·봇 대상에 동일하게 적용하고 사람 공격 의도는 집계하지 않는다. |
| 예약 점수 배율 | 다른 예약 0/1/2개 → ×1/×0.65/×0.35 | PRD 확정 초기값. 자기 기존 예약은 제외한다. 3개면 새 계획 추격을 거절한다. |
| 비양수 점수 계획 추격 | 점수 ≤0은 선택 제외 | 음수에 0.65를 곱해 오히려 점수를 높이는 부작용을 막는다. 생존 역공 예외에는 적용하지 않는다. |
| 예약 갱신 | 유효한 ATTACK 판단마다, 현재 약 200ms | 별도 탐색이나 행동 RNG를 사용하지 않는다. |
| 예약 만료 | 갱신 후 800ms | 현재 판단 주기 4회분, 24틱. 3단계 주기 변경 시 재검토한다. |
| 같은 tick 반영 | 결정 즉시 원자적으로 예약 | 다음 봇은 앞선 예약을 반영한다. 목표 변경 시 이전 예약을 해제한다. |
| 판단 순서 | 실제 판단할 봇만 전용 시드 RNG로 셔플 | 진단 여부와 행동 RNG에 영향을 받지 않는다. 비판단 tick의 가벼운 조향은 유지한다. |
| 예약 ID | 공격자 ID·life ID / 대상 ID·life ID | 새 생명·새 참가자에게 오래된 예약을 넘기지 않는다. |
| 즉시 해제 | ATTACK 이탈·목표 변경·공격자/대상 사망·이탈·계획 무효 | TTL을 기다리지 않는다. 대상 선 소멸과 경로 실패를 포함한다. |

셔플은 성격·이름·특성 RNG와 겹치지 않는 고정 seed domain을 사용하고 기록한다. 예약 목록에 전역 위치를 넣거나 봇 관측으로 전달하지 않는다. ATTACK 점수·허용 여부만 디렉터가 조정한다.

## 4. 생존 역공 예외

일반 추격이 상한을 우회하지 않도록 아래 조건을 모두 충족해야 한다.

| 조건 | 제안 초기값 / 판정 |
| --- | --- |
| 보호해야 할 선 | 내 노출 선이 실제로 존재함 |
| 위협 상대 | 현재 지역 관측에서 내 선을 위협하는 바로 그 상대의 선을 절단함 |
| 상대 절단 ETA | 유한하고 1.0초 이내 |
| 귀환만으로 생존 가능성 | 상대 절단 ETA +0.15초 < 내 귀환 ETA. 귀환 ETA가 불명확하면 예외로 승격하지 않음 |
| 내 역절단 ETA | 0.75초 이내 |
| 역절단 선행 여유 | 내 절단 ETA +0.15초 < 상대 절단 ETA |
| 상대 귀환·우리 귀환·경로 안전 | 기존 상대 귀환 ETA·선 길이·경로·역절단 검사 통과 |
| 위협 해소 후 | 계속 추격하려면 정상 예약을 새로 확보함 |

예외는 예약 상한을 넘을 수 있지만 일반 계획 추격 예약 3명 상한은 유지한다. 예외 횟수·예약이 이미 3개인 상황의 예외·거절 사유를 별도로 집계한다. 현재 1.25초의 일반 짧은 공격 기회 판정은 이 예외와 구분한다.

## 5. 구현 후 검증

- 사망·점령 사건 중복 방지, N칸 경계, 관측 제한, 체류·재진입·반복 window·대기 시간, 같은 진입의 접근/침입 중복 방지를 자동 검증한다.
- 자기 부활 후 기억 유지·감쇠, 상대 ID 교체 시 분리, 공개 사망 감쇠의 한 번 적용을 확인한다.
- pressure·원한 효과의 성격별 범위 준수와 HUD·observer 유무에 따른 판단·행동 RNG·예약 순서의 일치를 확인한다.
- 예약 3명 상한, 같은 tick 결정·해제·만료·자기 갱신, 사람·봇 동일 적용, 예외 해소 후 정상 예약 재확보를 확인한다.
- audit이 실제 2단계 디렉터 경로도 실행하도록 연결하고, 41980bd의 동일 fixture·시드·시간과 비교한다. 배정 시드 변경을 AI 효과와 섞지 않는다.
- 공격 시도·성공·포기·사망·점령·벽 사망과 tick 비용을 함께 비교한다. 짧은 성격 audit의 공격 표본이 작으면 성공률만으로 결론내리지 않는다.
- 반복 침범에 대응하지 않은 장면과 여러 봇의 근접 상황을 다시 관전한다. 기억이 유효 기회에서 작동하는지 확인하고 전략 전환 문제는 3단계 검증에 남긴다.
