## 색상

유료 색상을 16개에서 32개로 늘렸다. 무료 기본색까지 상점 선택지는 33개다.

- 무료 기본 민트: `#16CDB1` 유지. 선명 모드에서는 기존 `#00C49A`.
- 유료 민트: `#80DBC0`으로 구분. 선명 모드에서는 `#55D6AD`. 기존 `mint` 상품 ID와 보유 기록 유지.
- 추가: 스칼렛, 살몬, 살구, 앰버, 레몬, 에메랄드, 크림, 그라파이트, 터쿼이즈, 아이스 블루, 인디고, 라벤더, 로즈, 와인, 모브, 코퍼.

각 색상은 마커·영토·선·보호막·효과에 기존 방식으로 적용한다. 기본·선명 모드 양쪽에서 슬롯/상점 색상 변환의 RGB 중복과 16인 색상 배정을 검증했다. 온라인의 기존 클라이언트별 표시 방식과 프로토콜은 유지한다.
