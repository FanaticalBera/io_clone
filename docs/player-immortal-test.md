# 플레이어 무적 후반 테스트 — 2026-10-15

## 실행

S24+에 **HEXHOLD 무적테스트** 앱을 별도 설치했다. 패키지는 `com.hexhold.game.immortal`이며 기존 `com.hexhold.game` 앱과 데이터는 유지한다. 테스트 앱의 **싱글 플레이 · 무적 테스트**로 시작하면 직접 조작하는 사람에게 무적이 적용된다. LAN의 사람이나 봇에게 자동 적용하지 않는다.

## 정확한 실험 규칙

- 플레이어의 기존 선·동시 생성 선 절단, 영토 점령에 의한 탈락, 벽 사망, 영토 소실 사망을 차단한다. 사망에 따른 꼬리 제거·영토 전체 중립화·생명 초기화·상대 처치 보상이 발생하지 않는다.
- 벽을 뚫고 나가는 기능은 아니다. 경계에서 멈출 수 있고, 방향을 바꾸면 다시 이동한다.
- 출발 거점 7칸은 적이 점령하지 못하고, 영토 연결이 잘려도 이 거점을 유지한다. 모든 땅을 잃어 귀환·확장이 불가능해지는 이전 봇 실험의 한계를 피하기 위한 최소 거점 보호다.
- **출발 거점 외에 새로 먹은 땅은 기존처럼 빼앗기거나 연결 단절로 중립화될 수 있다.** 영토 전체 보호나 자동 확장은 적용하지 않았다.
- 나머지 13봇의 행동·정보·이동·사망·3초 부활 및 안전 부활 조건은 기존과 같다. 마커·인게임 효과·가로 화면 구성도 유지한다.

## 기록

5초 게임 시간 간격으로 점유율, 사망·처치 수, 살아 있는 봇 수, 현재 부활 차단 봇 수, 중립 땅 비율, 실제 부활 성공·차단 누적 횟수를 수집한다. 50%·70%·90% 최초 도달 시점도 따로 기록한다.

테스트 앱 WebView의 `window.__HEXHOLD_PLAYER_IMMORTAL__.read()`로 현재 기록을 읽는다. 30초 게임 시간 간격 및 세션 종료 시 테스트 앱의 `localStorage['hexhold.playerImmortalTest.last']`에 저장하며, `.last()`로 저장본을 읽을 수 있다. 최대 최근 1,440개 표본(약 2시간)과 도달 기록을 유지한다. 게임을 종료하기 전까지 최신 일부 표본은 메모리에만 있을 수 있다.

이 데이터는 일반 플레이 난이도·실제 생존 가능성의 검증이 아니다. 후반 영토와 남은 중립 공간에서 기존 부활 조건이 어떻게 작동하는지 보는 실험 자료다. 작은 출발 거점 보호 역시 실험 조건에 포함하여 해석한다.

## 검증

- 별도 사본의 클라이언트·서버 타입 검사 통과.
- 무적 전용 테스트 13개 통과: 여섯 사망 원인, 실제 봇의 선 진입, 시작 거점과 일반 영토의 탈취 차이, 연결 단절 때 거점 유지, 벽 접촉 후 방향 전환, 봇 사망·3초 부활, 실제 PracticeSession의 인간 조작 및 기록.
- 무적이 설정되지 않은 공유 엔진은 원래 엔진과 seed 4의 600틱 동안 30틱 간격 상태가 동일했다.
- APK 빌드 성공. 실제 패키지·앱 이름을 확인했다.
- S24+에서 테스트 APK의 실제 조이스틱 터치를 검증했다. 입력 후 진행 방향이 반영됐고, 플레이어 ALIVE·사망 0·보호 거점 7칸·게임 틱 진행을 확인했다. 폰에서 사망 원인을 강제로 주입한 검증은 아니며, 각 사망 원인의 차단은 위 엔진 테스트로 확인했다.
