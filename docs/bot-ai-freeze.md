# 봇 최종 채택·닉네임 통합·동결

2026-10-14. 사용자가 seed137 관전과 직접 플레이를 마치고 **B-quiet+C+안쪽 경계**를 채택했다. 이상 신호 없음. 사람 플레이 기록은 **6분30초 / 31.3%**이며, 자동 fixture의 성장 수치와 구분한다. 아래 검증을 마쳤으며 master 병합 후 봇 기능을 동결한다.

## 최종 검증

|항목|결과|
|---|---|
|고정8시드240초 보유 시간 평균|3911.12 → 4023.59 (+2.88%)|
|240초 사망|178 → 176, 벽 사망0|
|중거리16개|11/16 유지, 실패6·10·13·14·16|

|확장 audit 비간섭|44개 모두 궤적·메모리·다음 RNG·예약 일치|
|닉네임 통합 후 전체 테스트|689일반통과 + 8기대실패, 일반실패0·skip0 / 102파일|
|타입·클라이언트 빌드|통과|

240초·비용은0a5b3d4에서 검증한 바이트 동일 행동 소스의 결과를 재사용했다. 닉네임 이외의 판단 소스는 바뀌지 않았고, 통합 후 같은8시드120초의 입력·이동·소유·선·생명 궤적 해시가 모두 원본과 같았다. 보유/사망의 엄격한 방향 신호는 구분 불가다. 확장 audit은 고정 배치·memorySeed·사람 루프1024개를 새로 실행했으며 표본을 바꾸지 않았다. 실제 재배치 회수4칸·사망0의 기존 테스트도 유지했다.

- B-quiet+C+안쪽 경계: **3.37ms/tick**
- 추가분: **-0.293ms/tick (-8.02%)**

observer 없는120초8시드3회, 같은세션 AB/BA 교차, 각 버전seed19 warmup1회 제외, 외부테스트 겹침0이다. 이는 안쪽 경계를 추가한 버전 전체의 한계 비용이며 동선 변화도 포함한다. helper 함수 자체의 독립 실행 시간으로 해석하지 않는다. 원본과 시드별 값은 [안쪽 경계 비용](../evidence/bot-inner-anchor-adoption/cost.json), [240초 보고](bot-ai-inner-anchor-adoption.md)에 있다.

## 닉네임

승인한 [288개 목록](bot-nickname-pool-review.txt)의 순서를 코드에 그대로 통합했다. 1~48은 원래 배열을 보존했다. 길이최대10자, NFKC중복0, 유사쌍0,1280×720 PC HUD·순위표 잘림0이다. 실제 앱의 로컬 폰트로 검사했다.

일본어229~248번20개는 배열에 유지하되 **기본OFF**, 자동 배정은268개다. 공통 플래그는 src/shared/bot-roster.ts의 BOT_NICKNAME_FLAGS.japanese=false이며 연습·LAN·온라인 기본값에 같이 적용된다. 개별 배정 fixture는 japaneseNicknames:true/false로 명시할 수 있다. 실기기 일본어 표시는 아직 검증하지 않았으므로 자동으로 켜지 않는다.

## 동결 범위

사용자 결정대로 뒤쪽 침입자 인식/자기 땅 감지는 넣지 않았다. [기존 관전 분석](bot-ai-seed137-player-review.md)의 먼 피해 대응·연결 단절 중립화 기억·HOME_CAPTURE 예측은 이번 동결의 미해결 기록으로 보존한다. **동결 이후 봇 동작 변경은 성능 PRD 이후로 미룬다.** 이번 결과를 이유로 추가 성장·안전·공격 튜닝을 이어 가지 않는다.

사용자 승인 순서: 최종 자동 검증 → 닉네임 통합 검증 → master 병합 보고 → 봇 동결. 원격 push는 별도 사용자 결정이며 이번 요청에 포함하지 않는다.
