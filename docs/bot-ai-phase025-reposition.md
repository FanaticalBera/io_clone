# 2.5단계 ③ REPOSITION 결과

2026-10-10. 사용자 승인 설계의 구현·기능 검증 완료. **균형 판정은 재검토 필요**: 같은 8시드에서 사망 94→113회(+20.2%)로 승인된 +20% 재검토 기준을 넘었다. 3단계와 공격/가산점 튜닝은 진행하지 않았다. master에 반영하거나 push하지 않는다.

## 변경된 행동

새 확장을 만들 때, 자기 영토 안이고 선이 없으며 유효 피해 구역이 있는 봇만 재배치를 고려한다. 상대별 최근 10초 실제 피해 ≥6칸 또는 원한 ≥6이면, 피해 칸 3칸 이내의 자기 경계 중 내부 경로 11–20칸인 목적지를 최대 8개 평가한다. 승인한 P 식과 P>0 조건, 결정적 동률 순서, 무추첨 선택을 적용했다.

자기 땅 내부 경로를 별도 REPOSITION으로 이동한다. 실제 목적지 칸에 도착한 뒤 현재 관측으로 새 확장을 계획한다. 기존 확장 24칸·성격별 크기/선 한도·가산점 상한·V=0·기존 경계 6개+피해 경계 최대 2개는 유지했다. 재배치에 옛 확장 루프를 붙이지 않는다.

남은 경로의 소유권, 현재 머리가 자기 땅 안인지와 선 발생, 목적지의 경계/소유 조건, 가해자 ID 이탈, 관측된 머리와 현재/다음 3개 경유 칸의 거리 ≤2를 매 tick 검사한다. 구역 소멸·8초 제한은 일반 판단 시점에 검사한다. 정상 판단 주기는 200ms 그대로이며 즉시 중단/도착은 디렉터 due 순서에 포함한다. 종료 후 봇 전체 6초 대기로 상대 교체를 통한 대기 우회를 막는다.

재배치 중인 봇은 판단 사이에도 12칸 안의 모든 살아 있는 머리를 관측한다. 기존 경량 관측의 첫 머리 하나만 사용하지 않는다. 관측 밖 머리·선·방향·입력은 사용하지 않는다. 유효한 기존 공격은 같은 안전/예약 정책으로 전환할 수 있으며 REPOSITION 자체는 추격 예약을 잡지 않는다. 이동 물리·속도·점령·사망·부활 규칙은 수정하지 않았다.

## 지도와 HUD

선택 봇의 내부 경로와 목적지는 **주황**이다. 노랑 피해 기억 / 하늘색 예상 회수 / 초록 회수해 현재 보유 표시는 유지한다. 재배치 중에는 새 확장 계획이 아직 없으므로 하늘색을 표시하지 않는다. HUD에 가해자 번호·닉네임, 목적지, 초기 내부 거리, 실제 이동 칸, 경과 시간, 도착/중단 사유, 봇 전체 재시도 대기와 경계 탐색 제한을 표시한다.

A→B→A 지표는 한 생명의 세 재배치 선택이 30초 안이고, 서로 다른 가해자 A/B/A에 대해 각 이동에서 실제 머리 칸 전환 2개 이상과 연속 두 실제 변위의 각도 ≥120도를 모두 만족할 때 기록한다. 성공/중단을 모두 포함하고 미실행 선택은 제외한다. 일반 재배치 실행 횟수는 이동 >0, 미실행은 0으로 별도 집계한다. 자연 대전에서 0회라고 해도 검출기가 작동하지 않는다고 해석하지 않는다.

## 다음 판단

현재 구현은 기능 검증을 통과했지만 사망 +20.2% 기준에 걸렸고 실제 되찾기 증가도 입증하지 못했다. 3단계로 넘어가거나 성공으로 마무리하지 않는다. 승인 수치·안전 기준을 추가로 바꾸지 않았다. 특히 seed 19/31의 사망 증가, 도착 이후 새 계획에서의 사망, 공통 재배치가 성격 표현에 주는 영향을 검토해야 한다. 재배치 중 사망 1회를 전체 증가 19회의 원인으로 단정하지 않는다.

다음 수정은 하나만 제안한다. **기존 가까운 확장 후보 중 안전 검사를 통과하고 실제 피해 칸을 회수할 수 있는 D 후보가 있으면, 그 판단에서는 먼 REPOSITION을 시작하지 않는다.** 현재 재배치 선택은 일반 확장 계획보다 먼저 실행되므로 가까운 대응을 건너뛸 가능성이 있다. 단순히 가까운 경계가 있다는 조건만으로 막지는 않는다. 위험 검사를 완화하거나 P·D·V 수치를 함께 바꾸지 않고 이 우선순위 하나의 효과를 같은 8시드로 검증하는 후속 제안이다. **이번에는 구현하지 않았다.**
