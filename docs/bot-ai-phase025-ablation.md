# 봇 AI 2.5단계: 8시드 원인 분리 결과

2026-10-10. 기준 소스 `989b1a8`, 실험 브랜치 `codex/bot-ai-phase01`. **40개 대전 완료 / 2.5단계 미통과 유지 / 단일 수정 제안: V=0, D 유지.** 게임 행동을 수정한 결과가 아니라 격리된 소스 사본을 비교한 보고다. REPOSITION과 3단계는 보류한다.

## 사전 확정 조건

시드 **4·19·73·11·31·47·101·137**를 실행 전에 고정했다. 각 시드 R56, 스폰 반경 1(7칸), BOT 14명, 클래식, 안전 부활, 120초/3,600tick. 성격·특성 배정과 행동 시드는 모든 갈래에서 동일하다. 결과를 보고 시드를 추가하거나 제외하지 않았다. 40개 모두 120초 동안 RUNNING을 유지했고 벽 사망은 0이다.

피해 기록·누적·원한·HUD에 해당하는 묶음 ①은 모든 갈래에서 켠다. 기준군은 기존 성격별 경계 6개와 D=V=0이다. 나머지는 일반 경계 4개+피해 쪽 최대 2개(중복·부족분 보충), 내부 접근 10칸과 기존 모든 안전 검사·성격별 루프 한도를 유지한다. D는 칸당 0.5, V는 칸당 0.75이고 해당 갈래에서 비활성인 계수만 0으로 만든다. D/V 중첩과 합계 +6/기본 점수 50% 상한은 그대로다.

기준군의 기존 4·19·73 궤적은 이전 ①만 적용 결과 및 0384f9a 기준과 같았고, D+V의 같은 세 궤적도 이전 결과와 같다. 새 시드의 기준군을 0384f9a 원본 재실행이라고 부르지는 않는다. 같은 ① 기능을 둔 채 경계/D/V를 분리한 비교다.

판정은 같은 시드 안의 차이를 사용한다. 실행 전에 **8개 중 최소 7개가 같은 방향이며, 어떤 시드 하나를 빼도 합계가 같은 방향일 때만 탐색적 방향 신호**로 정했다. 그 외에는 **구분 불가**다. 이는 효과 없음과 다르다. 8시드의 방향 일관성 기준이며 통계적 유의성이나 전체 시드에 대한 보장을 주장하지 않는다. [고정 프로토콜·소스 해시](../evidence/bot-phase025-ablation/protocol.json)에 남겼다. 준비 실행기의 타입 선언/기존 프로토콜 재사용 처리만 수정한 해시 이력도 기록했으며 실험 소스·수치·시드·판정 규칙은 바뀌지 않았다.

## 상대 영토와 노출 선 거리 가설

계획 선택 시 예상 외부 경로, 사망 직전 중립화 전의 실제 선+그 tick의 pending 선을 기록했다. 선택 시 알고 있던 원한 상대 집합/최대 원한 상대/피해 가해자 집합을 구분하고, 실제 처치자의 당시 영토 거리도 사망 시 기록했다. 공개 소유권만 사용하며 관측 밖 머리·선·방향을 정책에 추가하지 않았다. 대상 영토가 없거나 노출 선이 없으면 0이 아니라 null이다.

아래는 ATTACK 전환을 제외하고, 원한 상대와 실제 거리 계산이 가능한 출발 계획이다. 없는 대상은 분모에서 제외하고 원시 요약에 결측 수를 명시했다.

**가산점 계획은 원한 상대 영토 가까이 붙는다는 가설은 관측과 일치한다.** D+V의 가산 계획 선택 거리 중앙값은 0칸, 가산 없는 계획은 28칸이다. 하지만 V만에서는 생환한 350개도 모두 선택 거리 0이고, D+V 생환 중 327/388도 0이다. 다른 성격·피해 상황·원한 유무가 섞인 관측 집단이며, V가 상대 땅을 먹는 점수라는 정의상 거리 0이 생기는 구조도 있다. **거리 0만으로 위험이나 사망 인과를 입증하지 못한다.** 사망 직전 거리 0 역시 즉시 위험 항 또는 하드 거절 기준으로 채택하지 않는다. [각 사망과 계획 연결 근거](../evidence/bot-phase025-ablation/death-plans.json)에 실제 값이 남아 있다.

## 단일 수정 제안과 합격 판단

제안은 **`revengePerCell: 0.75 → 0`으로 V만 비활성화하고 D를 유지**하는 한 가지다. D 값·피해 경계·원한 기억/판정·성격 배율·총 가산 상한·안전 검사는 그대로 둔다. 영토 거리 위험 항 추가나 성격별 새 배율을 동시에 넣지 않는다. 이번에는 실험/제안까지만 수행했으며 실제 게임 설정은 수정하지 않았다.

근거는 같은 조건에서 D+V→D만의 사망 감소와 총 점령 증가가 각각 7/8시드로 일관됐기 때문이다. 반면 되찾기/순영토 증가의 차이는 구분 불가이고, D만의 기준군 대비 사망은 +13.4%(5악화/3개선)이며 성격 수렴도 남는다. **V 제거를 2.5단계 전체 합격이나 안전성 증명으로 취급하지 않는다.** 수정 승인 뒤에도 성격별 대응과 피해 경계 선택 문제를 별도로 판단해야 하며 REPOSITION/3단계는 계속 보류한다.

프로젝트 타입 검사와 감사 스크립트 엄격 타입 검사 통과, 관련 Vitest 4파일/78개 통과. seed 19의 120초 대전에서 에피소드 관측 켬/끔의 실제 입력·매 tick 소유권/선/위치·생명 궤적 해시와 기존 감사 결과 전체(디렉터 예약 요약 포함)가 같다. 기존 3시드의 기준/D+V 해시도 모두 같다. 이번 변경은 감사 도구와 테스트에 한정되어 PC 화면·빌드·일반 게임 행동을 바꾸지 않았다. [검증 기록](../evidence/bot-phase025-ablation/validation.json).
