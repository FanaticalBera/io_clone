# 상점 가격 재조정 — 2026-10-15

## 승인한 가격

사용자가 전체 인하안을 승인하고 판매용 전설은 2,000~2,500코인으로 제안했다. 해당 범위의 가운데인 2,250코인으로 분리했다.

| 종류 | 기존 | 적용 |
| --- | --- | --- |
| 색상 | 300 | 100 |
| 기본 마커 | 500 | 250 |
| 이미지 마커 | 1,500 | 600 |
| 일반 특수 마커 8종 | 4,000 | 1,200 |
| 판매용 전설 특수 마커 8종 | 4,000 | 2,250 |

판매용 전설은 불사조·블랙홀·무지개·눈송이·벚꽃·킹 슬라임·다이아몬드·황금 드래곤이다. 컬렉션 전용 보상 마커는 기존 해금 조건을 유지한다. 기존 보유·장착·코인 데이터를 이관하거나 초기화할 필요 없이 신규 구매 시 새 가격을 사용한다.

## 판단 근거

- 일반 숙련자 기록: 9분 / 39.3% / 9킬 / 110코인.
- 사용자 무적 플레이어 실험: 약 6분 28초 / 100% / 29킬 / 392코인.
- 무적 완주 보상을 정상적인 매판 수급으로 가정하지 않는다. 보상은 기존 식인 기본 5 + 점유율당 2 + 처치당 3 + 완주 보너스 100을 유지한다. 가격 변경과 보상 변경을 함께 섞지 않았다.

## 검증

- 상점·보상·프로필 관련 단위 테스트 59개 통과. 정확한 금액 구매, 잔액 부족 시 무변경, 중복 구매 방지, 보유·장착·기존 지갑 보존을 포함한다.
- 클라이언트·서버·테스트 TypeScript 검사, 웹·서버·일반 APK·무적 테스트 APK 빌드 통과.
- 실제 오프라인 APK 웹 번들로 브라우저 구매·장착·저장 재로드 검증 통과: 링 250, 말랑냥 600, 궤도 정령 1,200, 불사조 2,250, 코랄 100. 5,000코인에서 각 1개 구매 후 잔액 600·보유·장착 상태와 통계 보존을 확인했다.
- 기존 Playwright shop suite는 로컬 HTTP 서버 응답 대기로 시작하지 못했다. 위 구매 검증은 해당 HTTP 서버에 의존하지 않고, 브라우저 요청에 실제 번들 파일을 공급하여 실행했다. 기존 e2e의 가격·잔액 fixture도 갱신했으나 그 suite 전체가 이번에 통과했다고 주장하지 않는다.
- S24+의 일반 앱과 별도 무적테스트 앱을 각각 데이터 유지 업데이트했다. 무적테스트 앱은 사용자가 홈화면으로 나온 뒤 갱신했다.
