# 재배치 시작 전 실제 조향 검사 제안

2026-10-12 · 행동 기준6c307e3 · **사용자 승인 후 시작 검사 구현 완료.** 구현 및 변경별 분리 결과는 [결과 보고서](bot-ai-phase025-safety-separation.md)에서 확인한다. 아래는 승인 당시의 제안과 원형 검증 기록이다. 이번 제안은 REPOSITION 시작 검사 한 가지이며,6004의 출발 경고 앞당김·3단계 전체 구현은 별도다.

## 문제와 재현 결과

seed137 /#7 몽실(안전지킴이·영토집착). t5761의 재배치 경로11칸은 모두 자기 소유다. 하지만 실제 위치·방향·회전 속도로 움직이면0.115초 뒤 경로에 없는2726(#3 소유)에 진입한다. t5761~5764 소유권 변경은0건이고, 실제5764 이동 중2726 진입→다음 상태5765 선1칸→TRAIL_EXPOSED 중단이다. 원인은 소유권 변경이 아니라 조향 중 경로 이탈이다.

제안용 사전 필터를 동결된 상태에서 대조했다. 기존 목적지 상한8개 모두 처음0.115초에 같은 외부 칸2726으로 새므로 제외된다. 판정·후보 선택 RNG 소비는0이었다. 정상 소유칸 통로 대조군은 예측을 통과했고 실제30tick 이동도 생존·선0칸·현재 자기 땅을 유지했다.

이는 통합 구현 전 **선택 검사 원형 검증**이다. 대조 필터는 기존 shortestPath 콜백에서 위험 경로를 제외하는 방식이고, 실제 구현은 아래대로 기존 점수 순서를 보존하며 양수 후보만 검사한다. 현재 게임의 원래 경기를 그대로 재생했고 첫3600tick 입력·소유권·위치·선·생명 해시가6c307e3 audit과 일치한다. 이 결과를 새 자연 대전의 개선이나 전체 균형 통과로 해석하지 않는다.

## 안전한 소유 대체 경로가 없었던 점

t5761에서는 기존 즉시 안전 모듈이 시험한 소유 인접 경로도 모두 불통과했다. 재배치를 취소하면 자동으로 자기 땅에 머문다고 주장하지 않는다. 목표는 "이미 물리적으로 자기 땅을 벗어나는 후보를 안전한 내부 이동으로 취급하지 않기"다. 다른 동작은 기존 일반 계획 판단을 거치며, 실제 결과는 통합 후 검증해야 한다.

## 구현 후 합격·재검토 기준

1. 원래6c307e3 경기의5761 상태를 동결한 회귀에서 원래 재배치 후보 제외, 역할에 맞는 정상 소유칸 이동 후보 통과, 점수·동률 순서와 검사 상한8 유지, 새 검사 RNG 소비0을 확인한다. 같은 실제 경기에서 같은tick 장면이 다시 나온다고 요구하지 않는다.
2. 안전 대체 없음, 벽 근처, 급회전, 경로 밖 소유칸으로 먼저 휘었다가 외부 진입, 시작 뒤 소유권 변경, 여러 가해자, 생명 변경을 검증한다. 실제 이동을 사용하고 성공하지 않은 재배치를 도착/되찾기로 세지 않는다.
3. HUD 켜짐/꺼짐의 판단·입력·RNG·예약 순서 동일, 정상 공격/귀환/기존 재배치 중단 조건 유지.
